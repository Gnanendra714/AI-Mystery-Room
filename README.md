# AI Mystery Room

A single-player fictional investigation game. Turn a story seed into a case, inspect evidence, make one accusation, and see an evidence-grounded reveal.

## Requirements

- Node.js 20 or later and npm 10+
- MongoDB for persisted cases in a configured deployment
- Google Gemini API key for AI-generated cases

## Quick start

1. Copy `server/.env.example` to `server/.env` and configure the values. `MONGODB_URI` and `GEMINI_API_KEY` are optional in local fixture mode.
2. Install dependencies: `npm install`
3. Start both apps: `npm run dev`
4. Open the Vite URL shown in the terminal (normally http://localhost:5173).

Without MongoDB and Gemini credentials, development mode uses a deterministic fictional case fixture and in-memory storage. This keeps the full game flow playable locally; it is not suitable for production. With both configured, cases are generated by Gemini on the server and saved in MongoDB.

## Commands

- `npm run dev` — client and API
- `npm run build` — client production build and server TypeScript compile
- `npm start` — compiled API server
- `npm test` — backend and frontend tests
- `npm run lint` — TypeScript checks

## Environment

See `server/.env.example`. The client only receives `VITE_API_BASE_URL`; provider keys and database credentials stay on the server. In production, configure the API origin, MongoDB, and Gemini credentials with the hosting provider's secret manager. The API serves the built client from `client/dist` when available.

Cases and attempts remain stored until manually removed in local MongoDB. Set a documented retention and deletion policy before public launch. Story seeds and generated cases are sent to the configured Gemini provider and stored by the app to deliver the game. Use fictional seeds only; do not submit real personal details or private communications.

## Deployment

See [GITHUB_PAGES.md](./GITHUB_PAGES.md) to publish the frontend at the project GitHub Pages URL. Deploy the API with the Render + MongoDB Atlas + Gemini walkthrough in [DEPLOYMENT.md](./DEPLOYMENT.md). The Render Blueprint is in `render.yaml`.

## Milestones

This repository establishes setup, contracts and validation, a fixture-backed API, optional Gemini generation, evidence investigation, accusation/reveal, and security hardening. Generated binary media, accounts, public sharing, leaderboards, and payment features are outside the MVP.
